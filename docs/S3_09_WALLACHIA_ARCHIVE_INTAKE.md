# S3-09. Проверка архива Wallachia со старого ПК

20 ноября 2026 года принят ZIP `s3-09-wallachia-old-pc.zip`. Контрольная сумма архива SHA‑256 `6c0dfed6299e958c651d690bb2757bc0a437686a5ecb2033122c5070a4d1f834`. ZIP содержит список целей и Python-скрипт поиска. Сохранённые матчи и отчёт о поиске на старом ПК в архив не входят.

Список содержит 276 уникальных ID карт, 114 ID серий OpenDota и 138 ID встреч PandaScore. Последние два списка относятся к разным источникам. Складывать их размеры для оценки количества серий нельзя. Сохранённый каталог OpenDota содержит выпуски PGL Wallachia Season 3, 4 и 5 с ID 17891, 18058 и 18358 соответственно.

Сверка с локальным реестром просмотра `.tools/s304-series-reconciliation-r1.json` и зафиксированной выгрузкой карт `.tools/s309-development-inventory-r1.json` дала ноль совпадений и по картам, и по сериям OpenDota. Это результат по двум конкретным источникам. Для отбора независимой выборки нужна проверка файлов со старого ПК и подтверждение полного списка BO3 по каждому выпуску. В протоколе установлены минимум 100 пригодных серий и два турнира.

Быстрый текстовый поиск в `docs` и `.tools` выделил 22 файла. Совпавшие структурированные поля относятся в том числе к номерам серий из пространства OpenDota. По этим числам нельзя подтвердить просмотр целевых встреч PandaScore. Полный обход текущей копии остановлен без итогового отчёта после затянувшегося прохода. ZIP проверен по CRC, скрипт прошёл пробный запуск на синтетических данных с совпадениями во всех трёх списках, пропуском конфигурации и отказом при повторной записи. [Машинная сводка](evidence/s3-09-wallachia-archive-intake.json).

Чтобы подготовить недостающий отчёт, распакуйте ZIP рядом с папкой проекта на старом ПК. Запустите из папки с двумя распакованными файлами, подставив путь к старой копии проекта.

```powershell
python .\screen-wallachia-folder.py "C:\путь\к\dotaanalitic" --output .\wallachia-folder-old-pc.json
```

Перенесите `wallachia-folder-old-pc.json`. В нём пути, контрольные суммы и совпавшие идентификаторы. Дамп БД и конфигурация для этого шага не требуются. Если найдены совпадения или остались непрочитанные архивы, их нужно проверить по источникам до регистрации набора.
