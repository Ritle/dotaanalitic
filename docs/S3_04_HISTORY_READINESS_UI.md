# S3-04 — состояние проверенной истории в Draft Lab

Порядок дальнейшей работы уточнён владельцем: сначала [путь допуска и сквозной shadow runtime](S3_04_POST_DRAFT_ADMISSION_PATH.md). Указанная в конце исходная следующая задача по часам отложена как отдельный первый шаг; требования к prospective-оценке сохраняются.

14 ноября 2026. Срез `player-hero-observation-readiness-ui`.

У сохранённого полного драфта появился блок «Проверенная история». Он показывает число проверенных прошлых исходов, общий объём сохранённого среза, количество непрошедших проверку карт и время чтения/сохранения. Проверенная native-привязка карты по-прежнему отображается следующим блоком. Число проверенных исходов не считается количеством готовых обучающих примеров или доказательством готовности признаков.

Данные читаются из уже связанной со снимком записи SQL060 через owner-only `GET /api/v1/scenarios/:id/draft-captures/:revision/history-summary`. Запрос проверяет SHA записи, владельца, редакцию, hash сценария и сохранение наблюдения до cutoff. Несвязанная подготовительная запись не подставляется. Ответ небольшой: часы, nullable counts, коды причин и `forecastStatus: unavailable`. Нет исходных payloads, списка игроков, пересчёта признаков или обращений к поставщикам.

Состояния:

- Проверка сохранена: показаны наблюдаемые counts и причины отказа отдельных карт. Полнота внешней истории и пригодность для модели из этих чисел не следуют.
- История недоступна: counts остаются `null`. Отсутствие карт, отсутствие подтверждённого источника исходов и превышение лимита объясняются отдельно.
- Старая редакция без наблюдения: предлагается сохранить новую редакцию полного драфта. Старый cutoff и отсутствующие свидетельства не восстанавливаются задним числом.
- Ошибка чтения: отдельная кнопка повторяет GET; сохранение драфта и запросы провайдеров не запускаются.

Vue Query кэширует immutable ответ по capture ID, отменяет чтение при уходе и не повторяет его при фокусе окна. Родитель привязывает компонент к сохранённой редакции; несохранённые правки не меняют отображаемую историю. Причина лимита прежнего подробного снимка перенесена в «Данные снимка» с пояснением о независимой проверке истории, чтобы не перекрывать полезный компактный срез.

Новый код: `draft-history-summary{,-contract}.ts`, маршрут в `draft-capture-http.ts`, регистрация в `app.ts`, компонент `DraftHistorySummary.vue` и подключение в `DraftCapture.vue`. Shared exports, миграции, recipes и действующая модель V1 этим срезом не меняются. [Проверки](evidence/s3-04-history-readiness-ui.json).

Прежние снимки и критерии не переопределять задним числом. **GPT-6 Astra · High**.
