# Подписи аккаунтов в подготовленных составах

6 ноября 2026, продолжение ранее согласованной S2-01/role-owner-check после добавления страниц расписания. Текущий сбор V1 проверен штатной командой `status`: `not_started`, попыток 0, осталось 10, метрики и вероятность null. Окно сбора начинается 20 ноября, 03:00 МСК; оценка не ранее 2 декабря, 03:00 МСК.

## Что обнаружено и исправлено

В карточках подготовки общий текст «Аккаунт требует уточнения» показывался и для уже подтверждённых связей. Это особенно мешало при переносе четырёх известных игроков в новую команду с одним неподтверждённым участником. Для всех пяти строк выводилось одинаковое предупреждение.

Теперь подписи различают три случая:

- «Связь аккаунта подтверждена ранее» — текущий выбранный Steam32 и локальный игрок совпадают с единственной подтверждённой связью.
- «Предложенный аккаунт — проверьте и подтвердите» — найден кандидат, но соответствие ещё не подтверждено.
- «Выбран другой аккаунт — требуется подтверждение» — владелец изменил ранее связанный аккаунт в несохранённой форме.

Неоднозначность, отсутствие кандидата, отложенный поиск и конфликты сохраняют свои отдельные сообщения. Изменены только подписи карточки; правила автоматической подстановки, подтверждения аккаунтов и сравнения остаются прежними. Подтверждённая связь не означает гарантированное участие игрока в будущей встрече. Ручные правки не сохраняются автоматически.

## Проверка рабочего интерфейса

Использованы сохранённые страницы и существующая owner-сессия. Это проверка локального состояния источников, а не новое подтверждение актуальности всех составов.

| Встреча | Страница | Наблюдение |
|---|---|---|
| Nemiga Gaming — angry birds, `1785740` | 1 | Пять кандидатов Nemiga требуют подтверждения; сохранённая пятёрка Angry Birds подставлена. |
| Inner Circle x Insanity — Spirit Academy, `1785743` | 2 | Пять кандидатов Inner Circle требуют подтверждения; сохранённая пятёрка Spirit Academy подставлена, sailyn отображается локальным именем inori. |
| InterActive Philippines — Amaru Gaming, `1791736` | 2 | Есть отложенные поиски и неоднозначные аккаунты. Причины видны по игрокам, автоматического выбора спорных аккаунтов нет. |

Во всех трёх случаях сравнение правильно недоступно до подтверждения десяти разных игроков. Сохранение новых связей, составов, сценариев и прогнозов не выполнялось. Desktop и 360px проверены, ошибок страницы и переполнения документа нет. Отдельный синтетический браузерный сценарий проверяет частично подтверждённую пятёрку и замену одного аккаунта без записи в рабочую БД.

Первый просмотр выполнил штатную автоподготовку и изменил только кэш каталога и квоту OpenDota; остальные 80 из 82 public-таблиц сохранены. Отдельный счётчик реальных HTTP-попыток для этого просмотра не устанавливался; ноль внешних запросов не заявляется. Повтор после исправления использовал кэш и сохранил все 82 public-таблицы без изменений. Состояния заданий очереди, 340 карт, история игроков и модельные факты сохранены. Подробности — в [машинном отчёте](evidence/s2-01-roster-account-labels.json).

## Проверки и границы

Новый тест сначала воспроизвёл ошибку: ожидались четыре подтверждённые строки, получено ноль. После исправления прошёл, включая ручную замену, снятие подтверждённой подписи, отсутствие автоматической записи, недоступность сравнения и мобильную ширину.

Выполнены с PASS: `pnpm install --offline --frozen-lockfile`, `pnpm typecheck`, `pnpm build`, `pnpm --workspace-concurrency=1 -r --if-present test --maxWorkers=1 --no-file-parallelism` — **887 unit/CLI**; Playwright `automatic-roster.spec.ts roster-catalogue.spec.ts schedule-pages.spec.ts upcoming-compare.spec.ts` — **18 сценариев**, один новый. Отдельный green-повтор нового теста не прибавляется к 18. Браузерные тесты используют настоящую PostgreSQL в отдельных тестовых БД и синтетические источники; автоматических повторов нет.

Проверены 47 упорядоченных миграций, 245 защищённых файлов, 150 исходных модулей и совместимость замороженного bundle/runtime. Полные PostgreSQL/API, отдельный Node-набор, полный Chromium-набор, Python и Docker/Linux повторно не запускались. Проверка относительных Markdown-ссылок прошла; исходные предупреждения Node/Rollup не блокируют сборку. Общая S2-01/role-owner-check остаётся открытой: три встречи не доказывают полноту всех составов.

Первый live-скрипт ожидал сокращённое название источника в таблице, которая показывает полные названия участников. Исправлен селектор проверочного скрипта; первый запуск завершился до выбора встречи. Пароли/сессии/сырые данные и screenshots остаются в игнорируемой `.tools`. API/Web не перезапускались; Vue dev-server подхватил изменение. Миграций, изменений backend, модели, зависимостей и настроек нет.

Точная следующая задача — **S3-01/V1-evaluation/collection** с 20 ноября, 03:00 МСК по закреплённому протоколу; **GPT-6 Astra · Extra High**. Для дальнейших обычных UI-поправок достаточно **GPT-6.1 Sol · High** по принятой в проекте матрице. Общая проверка всех возможных составов остаётся открытой.
