## Первый срез: S2-01/BUG_REPORT/lineup-editor

Изменены только API-оркестрация поиска и Vue-интерфейс с тестами. Старый
`playerNameMatches` в ingestion остаётся механизмом широкого ручного поиска;

эта модель не использует роли. Смена самого игрока требует нового расчёта.

На главной откройте «Сравнить две команды», введите название, нажмите «Найти»
и выберите результат. Игроки выбираются таким же способом. В списке «Роль игрока»
выберите нужную позицию: занявший её игрок поменяется местами с выбранным.
