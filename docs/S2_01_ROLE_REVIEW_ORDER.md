# Порядок ролей в проверке составов

Обзор ожидаемых пятёрок выводит назначенные роли в порядке **Carry → Mid → Offlane → SemiSupport → Hard Support**. Порядок применяется к подготовленной пятёрке до сохранения связей, сохранённому составу и спискам подсказок ролей. Невыбранные кандидаты и неопределённые роли остаются после определённых, без автоматического назначения позиции.

При смене роли обзор переставляет строки. Роль остаётся у конкретного игрока; смена на занятую позицию использует прежний обмен двух назначений. Порядок исходных данных и поля ручного редактора сохраняются. Ники/аккаунты/stand-in/герои не привязываются заново по номеру отображаемой строки. Смена назначения требует повторного подтверждения как прежде.

Только UI: roleSortedRows создаёт отдельный массив отображения с теми же объектами строк, roleName задаёт согласованные подписи. Numeric rolePos1–5, HTTP/DB, idempotency/CAS, сохранённые шаблоны/сценарии, приоритет источников и модель V1 прежние. Сортировка не подтверждает историческую роль и не заполняет неизвестные позиции.
