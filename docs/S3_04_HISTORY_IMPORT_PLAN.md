## Как будет проверяться загрузка

Сбор сохранил проверенную проекцию нужных полей, но не исходные байты HTTP-ответов. Поэтому следующая задача должна явно обозначать адаптер `opendota-projection-replay-v1`, считать SHA от переданной проекции и отдельно сохранять исходный SHA в происхождении данных. Нельзя выдавать проекцию за оригинальный ответ. `knownAt` остаётся неизвестным.

Порядок в отдельной БД: проверка контрольных сумм → существующий importer с offline-адаптером → проверка исходов → preview/register недостающих серий → повторный импорт для связи с сериями → проверка исходов, связей и идемпотентности. Планирование новой записи команды или серии само по себе не создаёт её в рабочей БД.

Результат плана не является разрешением использовать карты для обучения. Потребуются отдельные проверки временной доступности, патча, истории до cutoff и новая версия исследовательской выборки. Зафиксированная оценка R1 и её недостаточное покрытие остаются прежними.
