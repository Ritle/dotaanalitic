## Как проверить

1. Откройте будущую встречу → «Подготовить составы» → «Подставить сохранённую пятёрку A/B».
2. В «Автоопределение ролей A/B» нажмите «Обновить профили API», если источники ещё не загружены или устарели. Кэш используется повторно.
3. Проверьте ник, canonical ID, позицию, источник подсказки и отдельное покрытие локальной pro-истории. Ник берётся из свежей PandaScore-записи по сохранённым player/team/tournament IDs либо из свежего STRATZ-профиля того же verified Steam32. По равенству ника люди не связываются. Неоднозначная, устаревшая или чужая запись не подписывает игрока; остаётся его ID.
4. Для ручной коррекции выберите игроков в нужных слотах ролей. Авто отключается после правки и не перезаписывает её при обновлении профилей. Для повторной автоматической расстановки явно включите авто.
5. Подтверждение 5+5 позволяет открыть сравнение. Сохранение сценария выполняется отдельной кнопкой.
