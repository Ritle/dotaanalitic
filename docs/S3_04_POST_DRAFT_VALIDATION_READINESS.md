# Подготовка независимой проверки после драфта

14 ноября 2026, срез `S3-04/post-draft-validation-readiness/kernel-and-inventory`. Родительская задача остаётся открытой: регистрация независимого эксперимента ещё недопустима. Этот срез добавляет исполняемую проверку готовности и численное ядро будущей оценки, а не подменяет проверку реальных источников синтетическими тестами.

## Что сделано

`tools/research/post-draft-validation-readiness.mjs` проверяет прежние frozen H2-источники, читает рабочую БД в repeatable-read/read-only транзакции и сохраняет отдельный immutable readiness report. В отчёте объединены IDs локальных карт и прежний H2 exposure blocklist, сохранены неизвестные series aliases, состояние capture/history/link, локальный каталог Tier1 и свежесть страниц кэша. Внешний SHA, code hashes и offline replay проверяют воспроизводимость. Существующий файл не перезаписывается.

Объединение двух инвентарей — **минимальный известный реестр**, не заверенная полнота всего проекта. Наличие записи в каталоге владельца не регистрирует независимый турнир. Наличие страниц кэша не доказывает полный знаменатель сыгранных карт. Поля registration/collection/deployable остаются false, даты и выбранный scope — пустыми. Ни общий флаг «данные проверены», ни ненулевое число captures не обходят ограничения.

`tools/research/post_draft_independent_evaluate.py` — отдельное численное ядро, не связанное с датами старого development holdout. Оно использует прежние функции метрик и парного bootstrap без изменения их файлов:

- Фиксированное окно 28 дней и 7 дней ожидания исходов; регистрация раньше окна. До конца ожидания — `not_due`, метрики отсутствуют.
- Неизвестный полный знаменатель/полнота серий и превышение 300 карт дают `insufficient`, без расчёта покрытия и метрик.
- Все известные карты области остаются в знаменателе, включая пропуски. Повторный map ID отклоняется. Exposed map/series, неизвестная серия, несовпадение состава, отсутствие исхода или поздняя запись исключаются; непригодный участник серии закрывает всю серию, включая случай пересечения границы окна.
- Временная граница `cutoff <= persistedAt < gameplayStartedAt`; равенство записи началу игры не допускается. Поддерживаются UTC часы с3или6знаками после точки, без округления native микросекунд до миллисекунд; проверены обе стороны границы в1μs. Отдельно сохраняются owner-asserted и verified-as-of strata.
- Прежние минимумы: 50 карт,25серий,10 исходов каждого класса,80% покрытия; log loss/Brier/ECE и 2000 парных whole-series bootstrap/PCG64 seed42. Положительный, отрицательный и недостаточный результаты сохраняют разные статусы.
- Ноль наблюдений даёт null rates. Missing H2 не превращается в 50/50 или calibrated fallback; baseline-only остаётся диагностикой.

**Ограничение ядра:** пока оно принимает только `syntheticOnly:true`. Реальный payload отклоняется с `VERIFIED_PROSPECTIVE_BUNDLE_ADAPTER_NOT_IMPLEMENTED`. Проверенные source clocks, labels, binding и сохранённые scores нельзя заменить переданными вызывающим кодом boolean-полями. Будущий адаптер должен воспроизвести реальные артефакты и построить ledger из доказательств, включая выбор первой допустимой попытки и все предписанные strata. Сам численный тест не доказывает наличие такого адаптера. Положительный тестовый статус — только `positive_synthetic_only`, activation/release/independentTestCompleted всегда false.
