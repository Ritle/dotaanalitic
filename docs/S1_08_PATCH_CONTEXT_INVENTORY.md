## Почему полные составы ещё не дают обучающую выборку

Все **360 мест игроков** разрешены для текущего описательного анализа. Отдельный вызов `resolveIdentity` с cutoff каждой карты подтверждает **22 места из 360** на восьми картах. Полные 10 исторических identity links есть только у карты **7378530387**; это ранее подготовленные доказательства S3-01. Нельзя утверждать, что исторических identity proofs нет вообще, и нельзя считать 22 места 22 независимыми картами.

Однако identity proof связывает аккаунт с человеком. Он не подтверждает, что этот человек был объявлен участником конкретной карты до старта. `MatchContextRepository.readAsOf` для обоих stages не находит доступных lineup/teams/heroes/roles ни на одной из 36 карт: причина `MISSING`, context observation IDs пусты. В БД есть 2507 импортных field observations, но все без known_at и без подтверждённого предматчевого context. Завершённые составы остаются пригодны для описательной статистики.

Свежие strict DatasetBuilder previews: **36 candidates / 0 eligible** для pre-match и post-draft, `NO_ELIGIBLE_MAPS`. Причины pre-match: `ACTUAL_LINEUP_INCOMPLETE`, `CONTEXT_LINEUP_UNAVAILABLE`, `CONTEXT_PATCH_UNAVAILABLE`, `CONTEXT_TEAMS_UNAVAILABLE`. Здесь `ACTUAL_LINEUP_INCOMPLETE` означает отсутствие прошедшего as-of проверку lineup, а не потерю десяти строк match_players. Post-draft дополнительно не имеет исторического hero context (`CONTEXT_HEROES_UNAVAILABLE`, `OBSERVED_HERO_MISMATCH`). Эти производные причины не означают доказанное противоречие текущих source hero IDs.

Устранение одного patch blocker не закроет остальные. Обучение, активация моделей и проценты побед не выполнялись.
