# S3-04 — остаточные файлы и границы охвата

15 ноября 2026. Завершена классификация **всех 19 файлов** из [предыдущего остатка](S3_04_SERIES_PROJECTION_RECONCILIATION.md). Новых native-карт и канонических связей серий нет. Реестр исключений остаётся **5674 карты / 1768 серий**; у 1923 карт серия OpenDota неизвестна.

## Что означали предупреждения

Два файла содержат группы Valve. Сверены все 155 групп и их native map IDs с закреплёнными источниками и реестром. Идентификаторы серий сохранены как Valve, без приравнивания к OpenDota. Прежние 56 групп без связи OpenDota остаются без этой связи; это не 56 новых карт.

Два файла — подтверждённые синтетические входы: проверены одновременно `capture.syntheticOnly` и `history.syntheticOnly`. Синтетичность относится к содержимому этих файлов, а не к любому совпавшему числу в другом источнике.

В остальных 15 файлах разобраны **336 полей**:

| Значение поля | Количество |
|---|---:|
| Название команды, например `[PeaDoors]` | 8 |
| Выражение шаблона Vue | 2 |
| Объявление типа/параметра API | 38 |
| Тип GraphQL, например `[Long]!` | 154 |
| Булев результат сравнения, а не ID | 2 |
| Счётчик серий, а не список ID | 1 |
| Явный unavailable/MISSING контекст серии | 72 |
| Локальный UUID серии в изолированной тестовой БД | 42 |
| Текст новости вне машинного реестра | 16 |
| Сообщение игрового чата вне машинного реестра | 1 |

Проверены все **16 локальных UUID** и их связи с уже известными native map/series. В исходном отчёте 46 упоминаний UUID: четыре были учтены прежде, 42 составляли остаток. Эти UUID не добавлены в production aliases. У 72 unavailable-контекстов проверены точный статус, причина MISSING и пустые observationIds; никакие значения не придуманы.

Текст новости и чата получил явную классификацию «вне машинного реестра». Это не утверждение, что произвольный текст никогда не содержит сведений о матче. Поддерживаемая явная ссылка `/matches/<id>` в таком поле оставила бы его нерешённым. Нераспознанное поле, изменившийся тип или новый файл не получают автоматического положительного решения.

## Решение о границах

**`residualDispositionComplete=true` относится только к этой очереди 19 файлов.** Проверены сохранённые JSON, известные структуры, явные native-ссылки и связанные доказательства. Исходные bytes/SHA и старые артефакты не изменены.

За пределами этого подтверждения остаются свободный текст, исходный код как произвольный носитель данных, логи, иные форматы, позднее созданные файлы и 269 исключений прежнего обхода. Пять прежних sourceIssues сохраняются в отчёте. **`completeGlobalInventory=false` не заменён на true.** Полнота ограниченного реестра не доказывает независимость любого нового эксперимента.

Ручной разбор этой очереди закрыт. Следующая работа должна исходить из конкретной будущей выборки и проверяемых условий её независимости. Для выбранной карты нужны собственные ID/series/временные свидетельства; неизвестную связь нельзя подменить соседней картой. Согласование области будущего теста не требует заново подтверждать составы всех старых карт.
