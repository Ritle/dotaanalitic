# S2-02 — сценарий конкретной карты

Запрос владельца 12 ноября 2026: убрать повторный выбор и подтверждение игроков/ролей после подготовки встречи.

В новой карте из назначения расписания интерфейс читает два локальных шаблона, подтверждённых владельцем. Переносятся только точные ID соответствующих команд, десять разных игроков и роли 1–5. Подтверждение позже выбранного среза не переносится. Нет полного состава или произошла ошибка загрузки — сохранение недоступно, показаны переход к подготовке встречи и повтор загрузки. Внешние API для этого не вызываются.

Сохранённый сценарий с плановым временем открывается как «Подготовка карты», в том числе по прямой ссылке Draft Lab. Игроки/роли доступны в свёрнутом по умолчанию блоке «Подтверждённые игроки и роли» для чтения в порядке Carry → Mid → Offlane → SemiSupport → Hard Support. Форм выбора игроков, смены ролей, автоподсказок и повторного подтверждения 5+5 здесь нет. Для замены игрока нужно подготовить новый сценарий из обновлённых составов встречи. Ранее сохранённая пятёрка и её роли не заменяются свежим шаблоном.

Редактируются название, контекст карты, герои и баны. «Сохранить карту» создаёт новую редакцию с прежними игроками; проверка уникальности/доступности героев и конфликт параллельной редакции остаются прежними. При переходе в Draft Lab сохраняется связь с назначением; ссылка расчёта возвращает к назначенной карте, если экран был открыт из неё. Прямая ссылка без назначения сохраняет отдельный сценарный путь расчёта. Самостоятельный ручной сценарий без планового времени сохраняет прежний редактор.

Текущая V1 рассчитывает вероятность **до драфта**. Герои не входят в её признаки. Сохранение пиков не пересчитывает выданные прогнозы. Вероятность после драфта требует отдельной реализации и валидации S3-04. Возможность указать номер карты не расширяет runtime: опубликованный V1 real-map путь по-прежнему поддерживает только карту 1.

Изменения локальны для UI: ScenariosView, опциональное отображение ролей ForecastLineups, чистый валидатор confirmed-map-lineups и соответствующие unit/browser tests. API, SQL, модель, её thresholds и immutable snapshots не изменяются.

Проверки: Frozen offline install, typecheck, 959 unit/CLI tests и build PASS. 16 уникальных Chromium/API/PG кейсов PASS с целевыми повторами; после сворачивания обзора ещё 8/8 PASS без retries. Live Aurora/GL read-only и мобильный экран360px PASS:0 business writes,0 JS errors,нет overflow.53 SQL checksum/docs links/diff PASS. Нефатальное предупреждение Vite о размере чанка остаётся.

В начальных браузерных прогонах исправлены тестовые причины: общий HTTP budget между сценарными кейсами, совпадение запроса Vite-модуля с маской template API и неоднозначный status-селектор во время поиска турнира. Production limits не ослаблялись. [Итоговая проверка](evidence/s2-02-map-workspace.json).
