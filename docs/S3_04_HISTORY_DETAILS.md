## Ограничения и воспроизводимость

`tools/research/post-draft-history-details.mjs` поддерживает `register`, `run`, `verify`. Manifest связывает proposal, discovery, frozen capture, локальные receipts/catalogue, код и тесты; зарегистрирован до первого HTTP. Используется прежний `OpenDotaClient` и общий PostgreSQL quota budget. Общий предел 100 HTTP attempts, максимум 2/map; повторы включены. Выполнено 8 попыток: 6 HTTP 200 + 2 HTTP 500. Квоты и cooldown не сбрасывались. Осталось 92 попытки в исходном общем бюджете, но это не разрешение повторно запускать завершившийся каталог; проблемная карта уже исчерпала свои 2 попытки.

Данные сохраняются отдельными неизменяемыми файлами. Второй `run` отклоняется до подключения к БД и HTTP. При ошибке предыдущие результаты сохраняются, остаток получает `not_attempted`. Для продолжения нужен новый зарегистрированный план с учётом уже сделанных попыток и сохранённых ответов; текущий manifest не меняется.

Полные тела ответов с chat/profile не сохраняются: используется прежняя ingestion-проекция. SHA оригинального ответа и SHA проекции различаются и записаны отдельно. У локальных receipts дополнительно сохранён original payload SHA, их JSON не выдаётся за исходные HTTP bytes. Реальное время fetched-at сохранено, known-at остаётся null. Synthetic markers отклоняются до проекции. Подтверждённые текущие связи с тем же числовым аккаунтом не объявляются исторически известным составом.
