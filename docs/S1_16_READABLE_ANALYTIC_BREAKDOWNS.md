# S1-16 — понятные распределения и ранняя опорная выборка

Срез №7: `S1-16/BUG_REPORT/readable-labels/analytic-breakdowns`.

В распределениях профессиональных карт, сыгранности пятёрки, личной истории
героев, союзных пар, контрматчапов и сохранённого отчёта рядом с прежним
числом карт показано название патча. В раннем pro-пуле и подробном prior
показаны герой, позиция и патч; N, победы, частота, масса prior, период,
веса и N_eff остаются исходными. Наблюдаемая или сглаженная частота не
становится вероятностью следующей победы.

Названия читаются из текущего локального каталога, отдельно от периода и
источников расчёта. Они не подтверждают историческую доступность патча или
героя и не меняют модель. У записи есть «Ключ записи» с точным локальным
ID. `null` — неизвестный патч; отсутствующая запись — недоступное название;
пустое имя — запись без названия. Эти состояния не подменяют друг друга.
Сохранённые отчёты и их hash/JSON не переписываются после переименования.

## Загрузка

`AnalyticDisplayLabels` собирает уникальные ключи на уровне отчёта,
передаёт готовые подписи в строки `PatchDistribution`, `SmoothingNote` и
`HeroPairValue`. Один и тот же патч в десятках пар не создаёт десятки
HTTP-запросов. Пустые/неизвестные наборы не запрашиваются.

Прежний private read-only `context-catalog` поддерживает batch `ids` также
для `patches` и `heroes`: до20 строковых bigint ID, до400 символов, без
смешивания с поиском/id/offset. Старые режимы и JSON сохранены; SQL уже
использует параметризованный SELECT/ANY. Лиги и игроки не получили batch.
Новые библиотеки, миграции и изменения shared packages не нужны.

На отчёт читается до200 уникальных ключей каждого вида, по20 в пакете:
не более20 запросов для двух видов. Для набора до20 ключей каждого вида —
по одному запросу; большой глобальный reference-пул требует больше пакетов.
Одинаковые пакеты используют общий5min Vue Query cache. Превышение бюджета
показывается явно; строки, числа и технические ключи отчёта не обрезаются.
Кэш не содержит статистики, признаков или решений по доступности.

«Обновить подписи аналитики» перечитывает только эти metadata. При частичной
ошибке успешные пакеты и прежние подписи сохраняются; «Повторить недоступные
подписи аналитики» запрашивает только неудавшиеся пакеты. Поиск фильтра и
другие каталожные подписи имеют прежние независимые cache keys/время чтения.
Обновление имён не запускает перерасчёт, импорт, provider HTTP или обучение.
