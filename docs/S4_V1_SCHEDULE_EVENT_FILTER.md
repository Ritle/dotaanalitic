# S4/V1 — фильтр турниров сохранённого расписания

Дата:2026-11-03. На `/upcoming` добавлен селектор «Турнир в сохранённом расписании». Он использует `tournament.providerTournamentId` PandaScore как строку; одинаковые имена и соседние BIGINT ID не объединяются. Подпись начинается с ID источника, затем идут лига и серия/стадия при наличии. Выбранный ID также показан отдельно: длинное название не скрывает идентификатор на мобильном экране. Отсутствующее название обозначено как неизвестное; исходный payload не изменяется.

По умолчанию показаны все предстоящие встречи текущей страницы. Фильтр работает в Vue по уже полученным данным и не отправляет запросов к провайдеру, не меняет API query/cache/source snapshots. Это до20 записей первой страницы, а не полный календарь. Выбор турнира не подтверждает его Tier1 membership и не заменяет runtime gate модели.

## Поведение

- Отдельно показаны число записей в source response, предстоящих на странице и видимых после фильтра.
- Опции строятся по всей сохранённой странице, включая уже прошедшие записи. Фильтр такого турнира может корректно дать0 предстоящих встреч. Неизвестное время сохраняется с подписью «Время не объявлено».
- При смене фильтра выбранная встреча и несохранённая ручная форма сбрасываются. Это явно указано рядом с селектором. Новый выбор требует повторного подтверждения; прежние ожидаемые составы не переносятся автоматически.
- Поздний roster response прежнего турнира не отображается вместо новой встречи: запросы по-прежнему разделены ключом турнира; панель старого выбора закрывается.
- Если после обновления cache выбранный ID отсутствует, фильтр сохраняется с опцией «отсутствует на странице», а не переключается молча на все турниры. Пустое состояние объясняет, что отсутствие на странице не доказывает отсутствие в полном расписании.
- Выбор локален открытому экрану. Перезагрузка browser/навигация создаёт экран с вариантом «Все турниры на этой странице»; обычное обновление source cache внутри экрана сохраняет фильтр.

Существующие ручное сопоставление, сохранённые назначения,5v5, прогнозы, journal и source clocks не меняются. Ни уровень турнира, ни roles/attendance/вероятность из фильтра не выводятся. Новых endpoints/миграций/dependencies нет.
