# S3-04 — входные данные условной проверки будущих карт

15 ноября 2026. Реализован локальный адаптер по [утверждённому протоколу B](S3_04_CONDITIONAL_FUTURE_HOLDOUT_PROTOCOL.md). Он подготавливает признаки и журнал пригодности карт; результаты матчей для оценки качества, регистрация турниров и публикация вероятностей в этот срез не входят.

## Что реализовано

[Чистый адаптер](../tools/research/conditional-future-holdout.mts) принимает отдельное описание целевой карты, подтверждённую историю pro-исходов для Elo, привязанную историю героев и объявленный перечень карт/серий. DTO проверяются Zod; идентификаторы остаются строками, время сравнивается в целых микросекундах.

Описание целевой карты содержит игроков, героев, проверенные стороны, время и происхождение. Исход, длительность, GPM, kills и произвольные дополнительные поля не принимаются. Собственная целевая карта не допускается и в историю — даже если этот пример затем исключается по другой причине.

Адаптер повторно использует неизменные `createV1FeatureBuilder` и `createPlayerHeroFeatureBuilder`. Для обеих формул исключаются целевая серия и карты, которые начались или завершились не строго раньше цели. История героев привязывается к той же карте, аккаунтам, временным полям и исходному receipt SHA. Пропавшую запись нельзя незаметно превратить в ноль сыгранных матчей.

Team A определяется по прежнему каноническому порядку ID команд; Radiant/Dire — по слотам `0..4` и `128..132`. Порядок элементов массива не определяет сторону. Изменение стороны Team A меняет знак обоих признаков.

Численный рецепт сохраняется. Условный протокол явно допускает позднее получение исторических сведений и фактических героев; оно остаётся помеченным реконструкцией. Отсутствие patch/role не подменяется догадками; действуют предупреждения прежнего hero-builder. Нулевая наблюдённая практика не означает нулевой опыт игрока.

## Отбор и покрытие

Входной журнал содержит выбранные native event IDs, границы окна, перечень целых серий и реестр исключений. Неполная серия, раскрытая ранее карта/серия, неизвестные участники, неверный выпуск турнира и выход серии за окно исключают всю серию из парного сравнения.

Каждая переданная карта остаётся в журнале с причинами. Если в объявленной серии есть карта, для которой отсутствуют входные данные, её ID сохраняется отдельно и учитывается в общем числе. Пустая выборка имеет покрытие `null`, а не нулевой процент. Неизвестная полнота входного перечня не считается доказанной полнотой источника.

`denominator` — число карт **объявленного локального перечня**, включая известные отсутствующие карты. `denominatorComplete` описывает согласованность этих деклараций; он не удостоверяет полноту API. Неподтверждённый pro-статус и отсутствующая связь с серией не позволяют установить этот флаг. До проверки источников результаты не являются независимой оценкой: `independentTest:false`, `deployable:false`.

## Воспроизводимый локальный файл

[CLI](../tools/research/conditional-future-holdout.mjs) сохраняет вход, результат, SHA утверждённого протокола, исходников/исполняемых зависимостей и отпечаток результата. Файлы создаются исключительно в `.tools`, без перезаписи. `verify` заново выполняет расчёт и сравнивает содержимое; одной пересчитанной контрольной суммы недостаточно для подмены результата.

```powershell
node tools/research/conditional-future-holdout.mjs build .tools/input.json .tools/result.json
node tools/research/conditional-future-holdout.mjs verify .tools/result.json
```

CLI сам компилирует исследовательский TypeScript. Для запуска тестов отдельно:

```powershell
node node_modules/typescript/bin/tsc tools/research/conditional-future-holdout.mts --strict --noUncheckedIndexedAccess --skipLibCheck --target ES2022 --module NodeNext --moduleResolution NodeNext --typeRoots packages/db/node_modules/@types --outDir .tools/s304-future-runtime
node --test tests/node/conditional-future-holdout.test.mjs tests/node/conditional-future-holdout-file.test.mjs
```

Входы сейчас являются декларациями доверенного локального адаптера. Объявленные `isPro`, receipt SHA и полнота серии ещё не сверяются этим CLI с подлинными файлами поставщика. Поэтому тесты используют явную синтетику; прохождение тестов не является измерением покрытия реальных будущих турниров. Адаптер не делает HTTP-запросов и не меняет БД, модель или журнал прогнозов.
