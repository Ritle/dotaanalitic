# S3-04 — источники номера и идентификатора карты

Пилот `player-hero-capture-target-resolution/source-pilot` выполнен 14 ноября 2026. Найден доступный явный номер карты **внутри PandaScore**. Прямую связь этого номера с native Dota map ID и точную UTC-границу начала игрового процесса подтвердить не удалось. Это ограничение автоматической привязки и независимой проверки post-draft модели; существующий условный V1 Elo остаётся отдельной работающей моделью.

Покупка тарифа не гарантирует нужное поле, его содержимое в этом пилоте недоступно. Не делаем запросы к альтернативным закрытым endpoints.

## Что можно использовать и чего пока нет

- **8/8** возвращённых game summaries содержат уникальные `id`, согласованный родительский `match_id` и явный `position`. Это наблюдение небольшой выборки завершённых встреч, не гарантия будущего покрытия. `match_id` здесь — PandaScore-встреча, `id` — PandaScore-игра; ни одно поле не принимается за native Dota map ID. `serie_id` турнира также не является Dota series ID.
- STRATZ подтвердил членство **3/3** фиксированных карт в сериях 1162593 / 1161942 / 1161402. Явный ordinal не установлен. В сохранённой introspection-схеме есть `MatchType.sequenceNum: Long` без описания: его значение и семантика в этом запросе не проверялись, считать его номером карты нельзя. У `SeriesType` найдены список `matches` и идентификаторы, без документированного номера карты. Сортировка по времени или array index не становится доказательством номера. Полнота списков серий отдельно не установлена.
- `startDateTime` трёх STRATZ-карт совпал с ранее сохранёнными ответами этого провайдера; прошлый аудит также сверял их с OpenDota. Совпадение timestamp не доказывает семантику game-zero.
- У всех восьми PandaScore summaries `end_at - begin_at - length` составляет 864–1069 секунд. Причину (draft/pregame, паузы, иные часы) ответ не определяет. Ни `begin_at`, ни `end_at - length` не признаны проверенным gameplay start.
- [Lifecycle PandaScore](https://developers.pandascore.co/docs/matches-lifecycle) описывает `begin_at` **встречи**: до начала оно равно расписанию, после перехода running — фактическое начало встречи. Это не документация точной границы игрового процесса отдельной Dota-карты.

Все receipts получены после выбранных карт, `knownAt:null` сохранено. Поздние метаданные могут помогать проверять фактическую карту, но не доказывают доступность драфта или состава до начала. **Native bindings: 0; verified gameplay starts: 0; primaryEligible/deployable:false.** Отсутствие поля в этой выборке не означает, что у поставщика никогда нет такого источника.

## Реализация и воспроизведение

Новые изолированные инструменты:

- `tools/audits/draft-target-source-pilot.mjs`: фиксированный SHA плана, максимум 4+1 запросов, общий учёт квот, timeout, запрет redirects/retries, ограничение ответа 2 MiB, безопасные ошибки, защита секретов, exclusive каталог попытки.
- `tools/audits/draft-target-source-report.mjs`: чистая проверка родительских ID/уникальности/явных номеров и членства серии; replay исходных SHA и кода, запись без перезаписи.
- `tests/node/draft-target-source-pilot.test.mjs`: синтетические проверки граничных случаев, не свидетельство реального покрытия.

Сырые ответы и receipts остаются в игнорируемой `.tools/s304-source-pilot-r1/`.
