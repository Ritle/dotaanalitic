# S1-08 — качество импортированного профессионального корпуса

2026-11-01: выполнен отдельный пункт v9 о раздельных статусах outcome/player/hero/team/series/timeline с группировкой по патчу, турниру и периоду. **Общий S1-08 corpus gate остаётся открытым:** 16 текущих карт не являются широким корпусом или готовым обучающим набором.

## Запуск и смысл отчёта

```powershell
pnpm corpus:quality 2000-01-01T00:00:00.000Z 2026-11-01T17:44:00.000Z .tools/corpus-quality.json
pnpm test:corpus-quality
```

Команда читает рабочую БД без сети и записывает новый JSON с запретом перезаписи. Период задаёт **время начала карт**, от включительно / до исключительно. Это текущий снимок хранимых оценок качества; конец периода не является историческим cutoff доступности этих оценок. Будущий конец периода и неупорядоченные даты запрещены. Чтение выполняется в REPEATABLE READ / READ ONLY. Более5000 карт дают `unavailable/WINDOW_TOO_LARGE`, без отчёта по произвольно усечённой выборке. Пустое окно даёт0 карт и нулевые счётчики.

В отчёт входят только `matches.is_pro IS TRUE`. Одна карта появляется один раз независимо от числа импортов. Для неё выбирается последняя сохранённая `match_quality_assessments` по `(assessed_at DESC,id DESC)`, с ID/версией/временем; прежние оценки не объединяются. Отсутствующая оценка сохраняет карту со всеми статусами `unknown`. Конфликт канонической записи считается отдельно, не скрывая карту. Статусы `eligible` означают результат соответствующей проверки импортера на момент оценки, **не** повторную верификацию label, актуального canonical context или пригодности для ML.

Связь оценки с receipt проверяется по ID из metrics, canonical map ID, provider match ID, provider и SHA снимка. Допускается повторная оценка одного source snapshot с новым import receipt; `raw_blob_ref` может ссылаться на первоначальный receipt. Неподтверждённая связь оставляет `receipt:null` и не увеличивает `linkedReceiptMaps`; сохранённые статусы оценки остаются видимыми. Хеши исходного HTTP-ответа — provenance, а не заявление о повторной проверке HTTP bytes.

Независимые счётчики каждого статуса есть для всего окна и групп `canonicalPatch`, `providerPatch`, `league`, `period` (UTC месяц). Неизвестные значения имеют отдельную группу. Числовая метка патча провайдера не заполняет canonical patch. Аномалия считается не более одного раза на карту. У каждой строки сохранены revision, sync time, assessment и source ссылки. Fingerprint покрывает request/maps/summary/strata/policy и не включает меняющееся время формирования отчёта.
