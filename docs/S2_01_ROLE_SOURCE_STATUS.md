# Состояния источников ролей

Срез `S2-01/role-owner-check/source-status` уточняет сообщения редактора. Алгоритм выбора ролей, подтверждение аккаунтов и сохранённые составы не меняются.

| Сообщение | Что делать |
| --- | --- |
| Данные устарели | Нажать «Обновить профили API». Старые роли исключены из автоматической подсказки. |
| Повторный запрос временно ограничен | Подождать перед обновлением; при необходимости выбрать роль вручную. |
| STRATZ не вернул профессиональный профиль | Использовать PandaScore, pro-историю или ручной выбор. Успешный HTTP-ответ не означает наличие профиля. |
| STRATZ не указал команду | Роль доступна для просмотра, но не применяется автоматически; использовать другой источник или ручной выбор. |
| В профиле другая команда | Проверить трансфер и сопоставление источника. |
| Команда или игрок не сопоставлены | Открыть «Сопоставление источников» и подтвердить проверенное соответствие. |
| Источник не указал роль | Использовать другой источник или ручной выбор. |

Подробности каждого игрока находятся в «Основания игрока», состояние ответа и время получения — в «Время обновления источников». При недоступных профилях рядом с кнопкой обновления есть краткая подсказка. Неизвестная команда отличается от несовпадающей только по свежему профилю того же проверенного числового аккаунта. Старый пустой ответ не описывается как актуальное отсутствие профиля.

Сообщения не запускают дополнительных запросов, не подтверждают участие в будущей игре и не дают разрешения на прогноз. Сохранённые ручные позиции сохраняют приоритет. V1 Elo не использует роли.

Изменения: `apps/web/src/role-source-status.ts`, компонент `RoleProfiles.vue`, unit-тесты и браузерный сценарий `role-profiles.spec.ts`. API, SQL и зависимости не менялись. Браузерные состояния синтетические и не являются измерением покрытия реального источника.
