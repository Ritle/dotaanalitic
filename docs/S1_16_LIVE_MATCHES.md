## Возможности и границы

Карточки показывают участников, турнир, BO, время и счёт выигранных карт. Фильтр объединяет группы одной редакции турнира. Источник — официальный [PandaScore running](https://developers.pandascore.co/reference/get_dota2_matches_running), доступный согласно [документации планов](https://developers.pandascore.co/docs/plan-reference). Используется существующий серверный PANDASCORE_API_TOKEN.

Счёт сопоставляется по ID команды, а не позиции в ответе. Неполный, неоднозначный или отсутствующий счёт отображается как «Нет данных»; отсутствующие время и участник не выдумываются. Список ограничен первыми 20 записями с предупреждением о возможной неполноте. Нет телеметрии отдельной карты, прогнозирования после старта, импорта исходов или обучения. Сохранённые прогнозы доступны через журнал.

Автообновление включено по умолчанию и проверяется каждые 15 секунд; успешный кэш действителен 60 секунд. Скрытая/offline вкладка приостанавливает запросы. Повторные клики и параллельные вкладки используют серверный кэш и общий lease. При ошибке сохранённый ответ остаётся с предупреждением об устаревании, повтор учитывает Retry-After. Отключение автообновления не скрывает старение данных. Пользователь читает кэш, обновлять источник может владелец.

## Реализация

- `apps/api/src/modules/live/{contract,provider-schema,provider,repository,service,http}.ts`: Zod-валидация, фиксированный endpoint, bounded retry/timeout/body, общий durable PandaScore quota, отдельный cache lease.
- `apps/api/src/app.ts`: регистрация GET /api/v1/live и POST /api/v1/live/refresh; общие session/owner/CSRF/origin guards.
- `packages/db/migrations/055_live_schedule.sql`: новая singleton-таблица кэша; прежние миграции неизменны.
- `apps/web/src/views/LiveView.vue`, `apps/web/src/live-refresh.ts`, router, HomeView, UpcomingView: страница, политика обновления и навигация.
- Тесты: API live-provider/live.integration, web live-refresh и e2e/live.spec.ts.

Клиент находится в API-модуле и переиспользует типы, Retry-After и quota существующего провайдера. Frozen research-пакеты не изменены. Ответ API содержит source SHA/endpoint/adapter/fetchedAt, computedAt, expiry/retry/refreshing и ready/stale/unavailable. Live-кэш не записывает канонические карты и не меняет расписание.
