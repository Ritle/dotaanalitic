# BetBoom: проверка источников и полноты списка

Срез `S1-16/BUG_REPORT/roster-source-fallback`, 10 ноября 2026, пересмотрен
после проверки фактов. Добавлять автоматический источник «недостающей активной
пятёрки» для этого примера сейчас некорректно.

## Наблюдения

1. Сохранённый `/proPlayers`, полученный 10 ноября в 18:44:15 UTC, указывает
   для OpenDota team ID8255888 только swedenstrong. Четверо прежних участников
   имеют другой team ID10331139 / DO KONCA. Это не разрешает объединить организации.
2. Отдельная проверка существующим клиентом OpenDota в 19:04:13 UTC:
   `/teams/8255888/players` возвращает 28 исторических записей, из них ровно одна
   с `is_current_team_member=true` — аккаунт175311897. Один HTTP request;
   результат не импортировался как текущая пятёрка или игровая история.
3. [Официальный сайт BetBoom](https://betboom.team/) на дату проверки сообщает
   о приостановке Dota 2-направления и переводе всего состава в неактив.
   На той же странице по-прежнему перечислены пять игроков. Сам список имён
   поэтому не доказывает активный состав. Дата вступления решения в силу на
   просмотренной странице не установлена; дата проверки не подменяет её.
4. [Страница Dota2ProTracker](https://dota2protracker.com/teams/betboom-team-8255888)
   при чтении вернула403; содержимое не проверено, обход ограничений не выполнялся.
5. В рабочей БД у локальной команды607 нет сохранённой числовой привязки PandaScore
   или STRATZ. Отождествление записей разных провайдеров по названию не выполнялось.

Объявление клуба и данные о регистрации в игре описывают разные факты.
Нельзя объявлять swedenstrong единственным действующим игроком BetBoom только
по флагу OpenDota, как нельзя восстанавливать активную пятёрку из прошлой карты.
Нужны раздельные понятия: регистрация у провайдера, выбранная пятёрка и статус
активности организации с источником.

## Изменение интерфейса

Карточка теперь отдельно поясняет список из0,1–4,5 и более5 игроков. Неполный
список явно отмечен, большая выборка не обрезается, пять записей не выдаются
за подтверждённую заявку. Есть ссылка на числовую карточку OpenDota и переход
«Выбрать пятёрку для сравнения». В переход передаётся только организация;
игроки не выбираются и прогноз не создаётся автоматически.

Пояснения одинаковы для всех команд. В коде нет имён/ID BetBoom, статуса
«неактивна» по числу записей или автоматического слияния организаций. Новых
API-клиентов, миграций, периодических запросов и изменений модели нет.

Это завершённая проверка причины и ограниченный UI-срез. **Общий автоматический
fallback составов не реализован** и не отмечается выполненным. Пункт№1 остаётся
частичным в части автоматического учёта активности; механизм обновления реестра
работает. Следующий шаг выбранного BUG_REPORT — **S1-16/BUG_REPORT/team-activity**:
статус активности с явным источником, фильтр и доступ к архиву (№4 и остаток№1).
Отсутствие локальных карт само по себе не должно скрывать команду.
