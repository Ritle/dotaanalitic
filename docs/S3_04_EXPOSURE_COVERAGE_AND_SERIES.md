Прочитано 156944183 байта. **14 файлов UTF-16** теперь разобраны с учётом BOM; прежние исходные bytes и SHA сохранены. Три больших датасета успешно прошли сканирование с явным лимитом 12 млн узлов: фактически 2334935, 2334929 и 2380077 узлов. Увеличение лимита не превратило ошибку в пустой результат; при превышении остаётся `resource_limit`.

Оставшиеся 55 файлов разделяются на:

- **38 файлов со ссылками на серии.** В явно помеченных OpenDota-полях найдены **24 различных series_id вне прежнего реестра**. Часть — нормализованные detail receipts с `projectionSha256`, а не сохранённые исходные HTTP-тела. Список есть в отдельном evidence; совпадение числа само по себе не устанавливает связь провайдеров.
- **2 файла синтетических входов.** Ранее они были проверены как synthetic-only. Этот общий сканер намеренно не переносит синтетичность с числового ID на произвольное другое упоминание; это не новые реальные карты.
- **15 файлов с непрочитанными текстовыми полями или нераспознанными идентификаторами.** Всего 219 `unparsed_structured_text`, 115 `unknown_local_or_invalid_series_id`, по одному `invalid_id_list` и `invalid_or_unsafe_map_id`. Среди них есть названия команд, схемы API, новости и локальные псевдонимы; они не выданы за отсутствующие данные или новую карту.

Пять прежних `sourceIssues` и 269 исключений исходного обхода сохранены. Файлы иных форматов и новые файлы после исходного обхода в этот фиксированный аудит не входят. `scoped_references_accounted` не доказывает отсутствие произвольных сведений в свободном тексте и не удостоверяет полноту всего проекта.

## Valve и OpenDota

Проверены **155 групп карт Valve** по сохранённым native map IDs:

| Сопоставление с реестром OpenDota | Групп |
|---|---:|
| Все карты явно связаны с одним ключом OpenDota | 94 |
| Часть карт связана с одним ключом, у остальных связь неизвестна | 5 |
| Ни у одной карты нет известной связи OpenDota | 56 |

Конфликтов между ключами и обратных конфликтов «один ключ OpenDota — разные Valve series_id» в этой выборке нет. Все карты этих групп уже присутствуют в списке исключений. У пяти частично сопоставленных групп остаётся **8 карт** без собственной связи OpenDota.

Это диагностическое согласие по общим картам, **не автоматическое объединение пространств серий**. Канонических aliases создано 0; связи отсутствующих карт не заполнены по соседней карте. Реестр остаётся **5674 карты / 1744 серии**, из них у 1954 карт ключ OpenDota неизвестен. Эти 1954 не являются новым требованием собрать составы или проверить каждую старую карту перед пользованием V1.
