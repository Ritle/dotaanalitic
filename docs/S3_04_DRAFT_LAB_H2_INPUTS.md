# Draft Lab H2 — параметры прогноза

23 ноября 2026 · ПК 2 · S3-04

Draft Lab H2 оценивает вероятность победы команды A **на одной карте после выбора героев** для выбранных пятёрок. В расчёте два численных признака. [Протокол эксперимента](../tools/research/player-hero-experiment-policy.json)

| Признак | Как рассчитывается | Что меняет его в драфте |
| --- | --- | --- |
| Разница среднего Elo пятёрок | Рейтинги игроков обновляются по исходам ранее завершённых проверенных профессиональных карт с учётом силы соперника. Из среднего Elo команды A вычитается среднее Elo команды B. Для модели разница переводится в `eloLogit = ln(10) × ΔElo / 400`. | Замена игрока меняет состав, для которого усредняется Elo. |
| Разница практики на выбранных героях за 90 дней | Для каждого игрока подсчитываются ранее завершённые проверенные профессиональные карты на выбранном герое. От числа карт `n` берётся `ln(1 + n)`. Из среднего по пятёрке A вычитается среднее по пятёрке B. Учитывается объём практики на герое. История побед и поражений используется при расчёте Elo. | Выбор другого героя или обмен героями между игроками меняет пары игрок–герой. Замена игрока может изменить оба признака. |

[Расчёт Elo](../packages/prediction/src/v1-features.ts) · [Расчёт практики](../tools/research/player-hero-feature.mts)

H2 использует логистическую регрессию. Замороженные коэффициенты для Elo-логита и разницы практики — `0,770853` и `0,135778` соответственно. Перед преобразованием в вероятность сумма делится на калибровочную температуру `0,811023`. У признаков разные единицы измерения. При прочих равных переход от нуля к девяти найденным картам на герое у одного игрока добавляет к оценке команды A примерно столько же, сколько **14 пунктов разницы среднего Elo пятёрок**. При росте исходного числа карт вклад каждой дополнительной карты уменьшается. [Коэффициенты и калибровка](S3_04_PLAYER_HERO_EXPERIMENT_FIT.md) · [Формула расчёта](../tools/research/player-hero-inference.mts)

Для расчёта нужны десять подтверждённых аккаунтов, десять разных героев и минимум пять пригодных профессиональных карт общей истории на игрока. По выбранному герою допускается ноль найденных карт. Количество отражает покрытие проверенной истории. Патч, роли, Radiant/Dire, порядок пиков и банов, пары и контрпики героев в текущую формулу H2 не входят. [Контракт признака практики](S3_04_PLAYER_HERO_FEATURE_CONTRACT.md) · [Требования к входам](../apps/api/src/modules/scenarios/draft-shadow-features.ts)

H2 остаётся исследовательским кандидатом. Коэффициент практики положительный, а преимущество над вариантом по одному Elo предстоит подтвердить на независимой выборке. [Историческая проверка](S3_04_PLAYER_HERO_EXPERIMENT_EVALUATION.md)
