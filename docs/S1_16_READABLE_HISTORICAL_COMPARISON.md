# S1-16 / BUG_REPORT №7 — исторические H2H и соперники

В `/compare` откройте «Соперники за период» нужной команды. Организации
показаны по две на странице с названиями и ссылками на карточки. Кнопки
перелистывания не пересчитывают сравнение. N и доля побед каждой строки
относятся ко всему выбранному периоду, а не только к странице.

В таблице H2H сохранены все доступные строки карт, стороны A/B, победитель
и совпадение с выбранными пятёрками. Для нужной карты раскройте «Составы A / B»:
показаны реальные исторические участники с никами и отдельными ссылками.
Порядок списка не задаёт роли и не доказывает текущий состав организации.
Внутренние ID доступны в «Данные записи»; ID карты остаётся видимым.

Подписи берутся из текущего локального каталога, а не из исторического ника.
Показаны источник и время чтения. Ники не объединяют личности; неизвестный
участник/соперник не получает вымышленного ID или ссылки. Пустой ник/название
и недоступные метаданные имеют отдельные подписи. Обновление имени не меняет
input, статистику, исходные карты, сохранённые редакции/отчёты или модель.

Общее `CatalogDisplayLabels` выделено из `ScenarioDisplayLabels`; последний
сохраняет прежний интерфейс для истории сценариев и отчётов. Используется тот
же приватный `GET /api/v1/catalog-labels` с прежними лимитами: две организации
и двадцать игроков. Одна открытая историческая карта требует до10 player ID,
страница соперников — до2 team ID. Для закрытых секций и полностью неизвестных
записей запросов нет. При повторяющемся точном наборе ID используется общий
кэш; запросы на отдельного игрока и массовая загрузка всех100 карт отсутствуют.
Числовые строки сохраняются без Number-преобразования.

Сохранены пять минут свежести, отсутствие автоматического retry/refetch при
фокусе, явное обновление, время последнего чтения при ошибке и отмена запроса.
Смена входа сравнения удаляет старый результат; поздний ответ подписей не
возвращает его. У широких таблиц остаётся внутренний горизонтальный скролл.
Backend, contracts, SQL, аналитика, ingestion, зависимости и V1 не менялись;
API/Web не требуют перезапуска.
