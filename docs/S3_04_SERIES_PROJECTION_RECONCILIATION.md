## Проверка происхождения

Для **30 detail receipts** проверены provider, endpoint `/matches/<id>`, ID файла/ответа/проекции, `projectionSha256 = SHA256(JSON.stringify(projection))`, отсутствие source issues и совпадение receipt с сохранённой строкой итогового отчёта. Отчёты связаны с manifest по SHA; manifest закрепляет неизменённый код `projectDetail`. Проверена временная последовательность регистрации и получения для `validated_http_projected`.

Ещё одна связь взята из сохранённой **последней строки лиги 20486**: карта `9086220626`, серия `1167282`. Проверены архивный SHA файла, provider, endpoint, league_id, native map ID и series_id. Это нормализованная сводка без отдельного projection SHA.

Оригинальные HTTP-тела в этих источниках не сохранены. Проверка проекций **не названа повторной проверкой raw payload**. Историческая доступность сведений до старта карты и пригодность для обучения из этого не выводятся. Все новые записи служат только исключению ранее просмотренных данных.

Прежние источники восстановлены с требованием точного воспроизведения всего родительского реестра: карты, серии, aliases и происхождение. Старый namespace-отчёт и его источники повторно воспроизведены. Новая ревизия хранит полные входные source rows и ссылку на неизменённые родительские артефакты. При конфликте сохранялись бы оба ключа исключения и явный статус конфликта; тихое объединение серий запрещено.
