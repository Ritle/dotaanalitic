# Назначение роли под игроком — S2-01/BUG_REPORT/player-role-cards

Прямое уточнение владельца от 11 ноября 2026: показывать пять игроков и
выбирать роль под каждым. Этот срез заменяет прежнее поведение №2,
при котором редактор переставлял игроков между слотами ролей.

В выбранном составе предстоящей встречи у каждого игрока сразу доступен
список «Роль игрока». В ручном сценарии и сравнении выбранный игрок
показан по нику; поиск другого открывается кнопкой «Заменить».
Данные аккаунта и ссылка на профиль раскрываются отдельно.

1. Выберите роль под нужным игроком.
2. Если она занята, другой игрок получает прежнюю роль этого игрока.
   Например, Carry → Mid у первого игрока меняет Mid → Carry у второго.
   Карточки остаются на месте; в составе сохраняются все пять разных ролей.
3. Проверьте назначения и подтвердите состав заново.

Ручная правка выключает автоподстановку. Её можно явно включить снова;
автоматическое назначение тоже сохраняет порядок карточек. Герой и отметка
замены принадлежат игроку. Герой отображается в отдельном редакторе драфта
под новой ролью этого игрока. Поздний ответ источника не отменяет ручную правку.

При сохранении сценария текущий порядок карточек сохраняется в открытом
редакторе. После полной перезагрузки страницы начальный порядок берётся из
сохранённых ролей; назначения ролей, героев и замен сохраняются. Порядок
карточек — локальное представление, не новый факт о составе.

Для API создаётся отдельная копия пятёрки, упорядоченная по роли.
Контракты, БД, сохранённые ревизии, данные провайдеров и модель не меняются.
Ожидаемая пятёрка остаётся отдельной необязательной базой сравнения.
Роли не добавляются в признаки V1 Elo.

Проверки и ограничения: [evidence](evidence/bug-report-player-role-cards.json).
Сохранение и прогнозы проверяются только на временных тестовых БД;
в рабочем сервисе проверяется несохранённая правка.
