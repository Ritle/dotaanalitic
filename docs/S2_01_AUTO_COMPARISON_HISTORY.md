# S2-01 — автоматическая история при сравнении

Владелец выбирает встречу, проверяет пятёрки и роли и нажимает **«Сравнить выбранные пятёрки»**. Локальное сравнение открывается сразу. Если у кого-либо из выбранных игроков меньше пяти нормализованных профессиональных карт, сервис ставит ограниченную загрузку истории этой пятёрки в очередь и показывает её состояние. После принятия карт сравнение перечитывается с теми же составами, ролями и фильтрами. Сохранять сценарий для этого не требуется.

По умолчанию выбирается до **25 уникальных карт на всю пятёрку за 365 дней**, включая прежние организации игроков. Источник — существующий серверный адаптер OpenDota. Общая карта игроков учитывается один раз внутри задания. Это ограниченная выборка источника, а не полная карьера и не гарантия готовности к прогнозу. Порог пяти карт управляет только загрузкой; Elo/model eligibility проверяется отдельно.

Повторное сравнение использует активное задание. Если оно уже запущено вручную с другими параметрами, сохраняются его фактические период и глубина. Завершённая попытка в период паузы также переиспользуется, даже если параметры отличаются от автоматических. После истечения паузы новая явная попытка сравнения может загрузить стандартную выборку. Частичная история, недоступность источника и лимиты не сбрасывают выбранные пятёрки или локальный отчёт. Автоматического цикла повторных скачиваний нет.

В раскрываемых **«Покрытие и параметры A/B»** доступны локальные N по игрокам, параметры задания, принятые/исключённые карты, ошибки и время следующей попытки. Отдельная ручная загрузка истории остаётся доступной для осознанного расширения глубины. Если такое задание ожидает обработчика, явное сравнение тех же пятёрок подхватит его с выбранными вручную параметрами. Проверка сохранённых проекций может пропустить карты при нехватке исходных записей; повторного скачивания в режиме продолжения нет.

## Правила и ограничения

- Проверяется общее локальное покрытие текущих подтверждённых числовых аккаунтов. Пустой результат фильтра даты, патча или турнира не означает отсутствие истории и сам по себе не запускает скачивание.
- Считаются только положительно установленные pro-карты `accepted/partial`, с победителем, положительной длительностью и завершением к моменту проверки. Публичные, неизвестные, будущие и незавершённые карты исключаются.
- Явно заданный исторический срез отключает автоматическую загрузку; современная история не подменяет сведения, известные тогда.
- Запуск доступен только владельцу. Проверки роли, активного аккаунта, Origin/CSRF и текущих identity bindings выполняются на сервере. У неуточнённого аккаунта остаётся объяснение; другая корректная пятёрка может загружаться независимо.
- Выполняются только выбранные задания очереди `opendota-player-history`, отмеченные через публичный API pg-boss приоритетом 100. Загрузчик создаётся лениво внутри API; общий worker и очередь истории организаций не запускаются. Прежние задания с приоритетом 0 не захватываются этим обработчиком.
- После перезапуска API опрос выбранного ранее автоматического задания может восстановить обработчик; обычное GET-чтение не повышает приоритет ручного задания.
- Используются прежние импортер, idempotency, квоты, Retry-After и provenance. Модель, артефакты, прогнозы и обучающие наборы этим действием не меняются. Миграций и новых зависимостей нет.
- Изменение состава/фильтров или уход со страницы отменяет ожидание браузера и скрывает прежний результат. Уже разрешённая серверная загрузка может завершиться в фоне.

## Реализация

API: `comparison-history-contract.ts`, `comparison-history.ts`, дополнение `PlayerHistoryService` и подключение в `app.ts`. UI: `ComparisonHistory.vue` и явный trigger из `UpcomingLineupCompare.vue`. Прогресс использует Vue Query; POST выполняется только по явному сравнению, последующие запросы — GET. После завершения выполняется один заключительный GET для актуального покрытия; ошибки не запускают новые POST.

Синтетическая проверка провайдера дополнена корректными Dire-слотами 128–132. Старые браузерные сценарии явно инжектируют синтетический источник, чтобы новая автоматизация не обращалась к реальным API из временных тестовых баз.

Результаты проверки и сохранности рабочего состояния: [evidence](evidence/s2-01-auto-comparison-history.json).
