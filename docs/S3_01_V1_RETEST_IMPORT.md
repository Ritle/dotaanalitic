- 1301 карта обработана штатным импортёром; 1293 новых map IDs. Первый проход: 1301 accepted, 7 точных повторов; одна ранее известная карта получила новую ревизию.
- Подтверждены 47 новых числовых связей аккаунтов; 280 существующих сохранены. 45 аккаунтов без numeric proof остаются неподтверждёнными. Ники не использовались для объединения истории.
- Создано 636 серий, 6 уже существовали. Карты повторно импортированы для привязки.
- Контрольный повтор: 1301/1301 duplicate, все 83 public-таблицы и задания очереди сохранили полные row hashes. Экспорт также не изменил БД.
- В итоговой выборке готовы **664/670 карт и 332/333 известных серий**. Для истории допустимы 2142 карты из 2232 канонических. Все исходные исключения и знаменатели сохранены.

## Проверки и границы

Шесть неготовых target maps — четыре без подтверждённой серии и две без проверенной связи аккаунта. Диагностический флаг отсутствующей canonical history у этих карт не означает, что нужно заново собирать историю всех участников.

73 PostgreSQL-проверки в шести отдельных тестовых БД — PASS; после исправления повторены все 6 retest-кейсов. Проверены конфликты и неполные аккаунты, native sides, исходы, серии, восстановление после частичного сбоя, запрет production-синтетики и идемпотентность. На рабочих данных пройдены manifest/plan replay, повторный импорт и read-only export.

Первый экспорт остановился до сохранения датасета: 46 161 104 байта превышали общий discovery cap 32 МиБ. Ошибка воспроизведена тестом. Для retest добавлен отдельный writer с лимитом 128 МиБ, совпадающим с существующим reader; общий helper и старые исполняемые файлы не менялись. SHA проверяется по точным байтам, запись остаётся exclusive, превышение UTF-8 лимита отклоняется до создания файла. Первый каталог export-01 сохранён; успешный повтор использует export-02. Это исправление объёма файла, без изменения допустимости данных или quality policy.

Независимый пересчёт проверил 21420 счётчиков опыта и 1461219 связей игрок–предыдущая карта. В историю входят только карты, завершённые строго до начала проверяемой. Серия с непригодной картой исключается целиком. Исходы и длительность проверяемой карты отделены от inputs.

Пятёрки восстановлены по фактическим участникам. Текущая доказанная связь того же аккаунта не переносит known_at в прошлое. Историческая доступность исходов использует зарегистрированное event-time допущение; это conditional retrospective dataset. Elo, пороги и первый FAIL не изменялись, новые метрики не вычислялись.

Для всех 939 прежних карт отдельно подтверждена сохранность исхода, начала/завершения, команд и исходных аккаунтов участников. Карта 8651546216 получила data revision 2→3 при сохранении этих полей.

До записи создана PostgreSQL custom backup, проверено её чтение pg_restore --list. Существующий кластер запущен без переинициализации. API/Web/general worker не запускались. 2684 файлов коллекции, 245 защищённых артефактов и 373 файлов прежнего frozen/current code сохранены. 14 заданий очереди неизменны; activeModels=0. Изменения public-таблиц при рабочем импорте перечислены в evidence; повтор и экспорт не изменили ни одной.
